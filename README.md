## Features

<!-- EDIT: keep only what your app actually does -->
- Add and manage daily habits
- Mark habits as complete each day
- Track streaks and progress
- Clean, responsive design that works on phone and desktop

## Tech Stack

<!-- EDIT: check package.json and keep only what's true -->
- React + TypeScript
- Vite
- Tailwind CSS
- Built with [Lovable](https://lovable.dev)

## Run Locally

You need Node.js and npm installed.

```sh
git clone https://github.com/<your-username>/strivish-habit-tracker.git
cd strivish-habit-tracker
npm install
npm run dev
```

Then open the local URL shown in your terminal (usually http://localhost:5173).

## Why I Built This

I'm a first-year B.Tech student. I built STRIVISH to practice building a complete web app and to make something useful for building daily routines.
While building it, I explored how login and signup flows work and how app data is stored and retrieved.
